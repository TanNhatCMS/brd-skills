# Glossary — Thuật ngữ Retail Banking (Anh–Việt)

Dùng thống nhất trong BRD. Cột tiếng Việt là nghĩa giải thích, trong BRD giữ nguyên thuật ngữ tiếng Anh.

| Thuật ngữ | Nghĩa |
|---|---|
| Acceptance evidence | Bằng chứng nghiệm thu — cách kiểm chứng một yêu cầu đã đạt |
| Address type | Loại địa chỉ: residential (nơi ở), mailing (nhận thư) |
| AS-IS process | Quy trình hiện tại |
| Audit trail / audit history | Lịch sử kiểm toán — bản ghi bất biến về ai làm gì, khi nào, qua kênh nào |
| Backdated correction | Sửa sai có hiệu lực ngược về ngày trong quá khứ |
| Baseline | Mốc hiệu năng hiện tại, dùng để đối chiếu target |
| Branch | Chi nhánh / quầy giao dịch |
| Business rule | Quy tắc nghiệp vụ — logic quyết định (khác requirement) |
| Contact centre | Tổng đài / trung tâm liên hệ khách hàng |
| Customer master record | Hồ sơ khách hàng chính — nguồn duy nhất của thông tin khách hàng |
| Delivery state | Trạng thái phân phối: pending / delivered / failed / reconciled |
| Downstream consumer | Hệ thống nhận dữ liệu từ master (core banking, cards, CRM...) |
| Effective date | Ngày hiệu lực của địa chỉ mới |
| Future-dated | Có hiệu lực từ một ngày trong tương lai |
| Immutable | Bất biến — không được sửa sau khi đã ghi |
| Least-privilege access | Chỉ cấp quyền tối thiểu cần thiết để làm việc |
| Masking | Che dữ liệu nhạy cảm (ví dụ: chỉ hiện 4 ký tự cuối) |
| Notification preferences | Kênh nhận thông báo khách hàng đã đăng ký (SMS, email, thư) |
| Partial distribution | Phân phối một phần — master xong nhưng có consumer chưa nhận được |
| PII (Personally Identifiable Information) | Dữ liệu định danh cá nhân |
| Reconciliation | Đối soát — kiểm tra và khớp dữ liệu giữa các hệ thống |
| Retention (policy) | Chính sách lưu trữ dữ liệu trong bao lâu |
| Stakeholder | Bên liên quan |
| TO-BE process | Quy trình mục tiêu |
| Traceability matrix | Ma trận truy vết — nối Objective ↔ Requirement ↔ UAT |
| UAT (User Acceptance Testing) | Kiểm thử chấp nhận bởi người dùng/nghiệp vụ |
